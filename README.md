# Angiosarcoma_DNA_methylation_analysis
DNA methylation array analysis for Angiosarcoma samples
  EPIC v2 DNA methylation array data
  based on minfi R package


### nbis_tutorial.Rmd ###
used minfi R package for QC and data processing of EPIC v2 DNA methylation array data
following nbis guidelines: https://nbis-workshop-epigenomics.readthedocs.io/en/latest/content/tutorials/methylationArray/Array_Tutorial.html

Data uploaded to GEO
